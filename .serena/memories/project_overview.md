ArtisanZ is a personal fork/custom branch of upstream Artisan, a PyQt6 desktop coffee roaster app. Work normally happens on branch `ArtisanZ`; `master` mirrors upstream. Main runtime entrypoint is `src/artisan.py`, flowing through `artisanlib.command_utility.handleCommands()` to `artisanlib.main.main()`. Core UI/app code lives in `src/artisanlib/` with custom ArtisanZ charge-target code in `charge_manager.py`, `charge_dialog.py`, and integration points in `main.py`/`canvas.py`.
