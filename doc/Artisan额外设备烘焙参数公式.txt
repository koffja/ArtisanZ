下面解释的是当前 artisan-adv-setting-260604.aset 里 5 个 Virtual 设备、10 个指标的意义。整体设计目标是：在烘焙过程中即时判断“现在的升温速度、温差结构、阶段进度是否健康”，而不是依赖背景曲线。

1. BT Δ Dry
公式：
pDRY * R2 / 60
含义：预计到干燥点还需要升高多少豆温。
- pDRY：Artisan 预测距离 DRY / 干燥结束还剩多少秒
- R2：当前 BT RoR，也就是豆温升温速度，单位通常是 °C/min
- /60：把每分钟升温换算成每秒升温
如果显示 10.0，意思大约是：照当前升温速度，到干燥点前豆温还会再升约 10°C。
用途：
- 判断前段火力是否足够
- 如果数值下降太慢，可能升温不足
- 如果数值快速接近 0，说明快到干燥点

2. BT Δ FCs
公式：
pFCs * R2 / 60
含义：预计到一爆开始还需要升高多少豆温。
- pFCs：预测距离 FCs / 一爆开始还有多少秒
- R2：当前豆温 RoR
这个指标比单纯看 ETA FCs 更直观，因为它告诉你“还有多少温度距离”，不是只有时间。
用途：
- 判断中段到一爆的推进速度
- 如果 BT Δ FCs 很大但 RoR 已经低，表示可能进一爆乏力
- 如果 BT Δ FCs 很小但 RoR 很高，可能一爆前冲太快

3. BT +60s
公式：
Y2 + R2
含义：按当前 RoR 粗略预测 60 秒后的豆温。
- Y2：当前 BT 豆温
- R2：当前 BT RoR，°C/min
因为 RoR 是每分钟升温，所以 Y2 + R2 可以近似代表 1 分钟后的豆温。
用途：
- 作为“短期趋势”指标
- 比当前 BT 更有前瞻性
- 帮助判断如果火力不变，豆温会不会冲过目标区间

4. ETA FCs
公式：
pFCs / 60
含义：预计距离一爆开始还有几分钟。
- pFCs 原本是秒
- /60 转成分钟
用途：
- 判断烘焙节奏
- 中段时尤其重要
- 例如显示 3.5，就是预计约 3.5 分钟后一爆

5. ET-BT Δ
公式：
Y1 - Y2
含义：环境温 ET 与豆温 BT 的温差。
- Y1：ET
- Y2：BT
这个值可以理解为“环境对豆子的热推动力”。
用途：
- 温差大：热量推动强，豆温容易继续上升
- 温差小：热推动弱，RoR 可能下降
- 温差过大：可能外部加热过猛，增加表面过热风险
- 温差过小：可能进入乏力、stall 风险

6. ΔETBT Slope
公式：
R1 - R2
含义：ET RoR 与 BT RoR 的差值。
- R1：ET RoR
- R2：BT RoR
它不是温差，而是“升温速度差”。
用途：
- 如果 R1 - R2 大幅为正：环境升温比豆温快，热输入增强
- 如果接近 0：ET 与 BT 同步变化
- 如果为负：豆温升速高于环境升速，可能是热惯性或 ET 回落
- 适合看火力调整后的趋势变化

7. RoR Accel
公式：
R2 - R2[-3]
含义：BT RoR 的短期加速度。
- R2：当前豆温 RoR
- R2[-3]：约 3 个采样点前的豆温 RoR
如果为正，代表 RoR 正在上升；如果为负，代表 RoR 正在下降。
用途：
- 判断 RoR 是稳定、加速还是衰退
- 比单看 RoR 更敏感
- 一爆前如果长期负值，可能表示 RoR crash 风险
- 如果长期正值，可能表示火力过猛或 RoR flick 风险

8. ETA Dry
公式：
pDRY / 60
含义：预计距离干燥结束还有几分钟。
用途：
- 判断前段节奏
- 辅助控制从回温点到黄点/干燥点的推进
- 显示 1.5 就是大约 1.5 分钟后到干燥点

9. Post-FC %
公式：
100 * (t - t{FCs}) / (t - t{CHARGE})
含义：一爆后时间占当前总烘焙时间的比例。
这个类似发展率，但它是在烘焙过程中实时变化的指标。
用途：
- 一爆前固定为 0
- 一爆后开始增长
- 帮助观察发展阶段占比
- 越接近下豆，这个数值越接近最终 DTR / development ratio

10. Post-FC Avg RoR
公式：
(Y2 - Y2{FCs}) / (dFCs / 60)
含义：一爆后平均豆温升速。
- Y2：当前豆温
- Y2{FCs}：一爆开始时的豆温
- dFCs：一爆后经过的秒数
用途：
- 判断一爆后的发展强度
- 如果太高，可能发展过猛
- 如果太低，可能一爆后能量不足
- 比瞬时 RoR 更平滑，适合看整体发展趋势

总结
这组 Virtual 指标可以分成 4 类：
1. 阶段预测
- ETA Dry
- ETA FCs
- BT Δ Dry
- BT Δ FCs

2. 热推动力
- ET-BT Δ
- ΔETBT Slope

3. RoR 动态
- BT +60s
- RoR Accel

4. 一爆后发展
- Post-FC %
- Post-FC Avg RoR

核心用途是让你在烘焙中更快判断：
现在升温是否健康？  
是否会太快或太慢进入下一阶段？  
RoR 是稳定、下滑还是反弹？  
一爆后的发展是否合理？

如果采样频率是3秒，我想在投豆之前有一个数值是能够计算10秒内的RoR，或是能够计算瞬时RoR（微分），目的是用来判断当前的炉内热量是否稳定，跟参考profile是否初始状态一致（假设相同投入生豆量）
1. 应该判断多长时间内的RoR更有意义？
2. RoR加速度是不是应该纳入考虑
3. 还有什么我没考虑到的部分应该纳入考虑？

建议不要用“10 秒 RoR”作为主判断。采样 3 秒时，10 秒只有 3–4 个点，太容易被探针噪声、风门波动、PID 周期影响。更合理是：
1. 判断多长时间内的 RoR 更有意义？
推荐主指标：30–60 秒 RoR
投豆前判断炉内稳定，我建议用：
- 短窗 RoR：15–21 秒
- 用来发现突然升温/降温
- 反应快，但噪声较大
- 主判断 RoR：45–60 秒
- 更适合判断炉内热量是否真的稳定
- 适合和参考 profile 的投豆前状态对比
- 长期趋势：90–120 秒
- 判断预热是否仍在缓慢漂移
- 如果 60 秒 RoR 接近 0，但 120 秒 RoR 仍明显正/负，说明炉体还没完全稳定
我会这样定义：
ET RoR 60s ≈ (ET_now - ET[-20]) / 60s * 60
采样 3 秒，60 秒就是约 20 个采样点。
判断标准可以是：
|ET RoR 60s| < 0.5 °C/min    很稳定
|ET RoR 60s| < 1.0 °C/min    可接受
> 1.5 °C/min                仍在漂移
如果你是小型样品烘焙机，可能要放宽到 1–2 °C/min。

2. RoR 加速度是否应该纳入考虑？
应该纳入，但不要直接看“瞬时加速度”。
RoR 加速度本质是二阶导数：
RoR Accel = 当前 RoR - 之前 RoR
它非常容易放大噪声。采样 3 秒时，如果直接算瞬时加速度，会跳得很厉害。
更建议用：
RoR Accel = RoR_短窗 - RoR_长窗
例如：
ET RoR Accel = ET_RoR_18s - ET_RoR_60s
意义：
- 接近 0：当前趋势和长期趋势一致，稳定
- 大于 0：炉温升速正在加快
- 小于 0：炉温升速正在减弱或回落
判断标准可以是：
|ET RoR Accel| < 0.5 °C/min    稳定
0.5–1.5 °C/min                有轻微趋势变化
> 1.5 °C/min                  初始状态不稳
所以答案是：要看加速度，但看平滑后的趋势差，不看瞬时微分。


3. 还应该纳入哪些指标？
我建议至少纳入这几类：
A. 绝对温度是否一致
只看 RoR 不够。
两个状态都可能 RoR 接近 0，但一个炉温是 180°C，另一个是 200°C。
所以要同时看：
ET 当前值
BT 当前值
ET-BT Δ
投豆前更重要的是：
当前 ET 与参考 profile 投豆前 ET 的差值
当前 BT 与参考 profile 投豆前 BT 的差值
B. ET-BT 温差
投豆前 BT 探针可能不是豆温，而是探针自身/炉内局部热状态。  
ET-BT Δ 可以反映炉内热分布是否接近参考状态。
如果：
ET 接近参考
BT 低很多
可能说明探针或炉体还没吸热到位。
如果：
ET 高
BT 低
可能是空气热，但炉体/探针热惯性不足。
C. 稳定时间
不要只看某一瞬间满足条件。
建议要求：
连续 60–90 秒满足稳定条件
例如：
|ET RoR 60s| < 1.0
且 |ET RoR Accel| < 0.5
且 ET 与目标差 < 2°C
持续 60 秒
这比单点判断可靠很多。
D. 控制输出是否稳定
如果有 burner / heater / fan / drum 数据，也应该纳入。
比如：
- 加热输出是否频繁大幅波动
- 风门/风速是否一致
- drum speed 是否一致
- PID 是否仍在大幅修正
因为炉温看似稳定，但如果控制输出剧烈变化，说明系统还没稳。
E. 环境条件
如果你要和参考 profile 对比，最好考虑：
- 环境温度
- 批次生豆量
- 生豆初始温度
- 上一锅结束后的间隔时间
- 是否连续烘焙
- 排风/鼓风设定
这些都会影响“相同投豆温度下的初始热量”。

我的推荐判断模型
投豆前可以做一个综合指标：
Ready Score =
ET 接近目标
+ ET RoR 60s 接近 0
+ ET RoR Accel 接近 0
+ BT/探针温度接近参考
+ ET-BT Δ 接近参考
+ 控制输出稳定
+ 条件持续 60 秒以上
