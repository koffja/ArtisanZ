**Goal:** Sync upstream Artisan v4.2.1 into ArtisanZ via the three-tier branch model (`upstream/master → master → ArtisanZ`), preserving Cotrix branding, GUI modernization (161 commits), and charge target feature.

**Architecture:** Follow the AGENTS.md official update flow strictly. Phase 1 updates `master` as a clean upstream mirror (zero conflicts). ```

```
       │
       ▼  Phase 1: clean merge
    master (e5bde5936 → 9349b8ffe)
       │
       ▼  Phase 2: conflict resolution
    ArtisanZ (ebbb61265 + upstream v4.2.1)
```

**Tech Stack:** git, PyQt6, Python 3.12+, pyqtgraph (ArtisanZ addition)

## Global Constraints

- **Three-tier branch model (from AGENTS.md):**
  - `master`: mirror-like official baseline. Only fetch/merge from `upstream/master`. NEVER add ArtisanZ features here.

- **Preserve:** Cotrix branding (`tastermatrix.com` in `__init__.py`), all `plus/` Cotrix integration, GUI modernization code (workspace mode, pyqtgraph, renderer plugins), charge target feature (`charge_manager.py`, `charge_dialog.py`).
- **Gain:** v4.2.0 Scale LCD direct connection, BBP metrics correction, acaia ISP + COSMO support, Schuilenburg PLC config, `loadableProfile` refactor, version bump to 4.2.1.
- **Upstream ref:** `upstream/master` at `9349b8ffe` (v4.2.1, 2026-06-30).
- **Merge base:** `e5bde5936` (2026-05-24, shared ancestor = current `origin/master` HEAD).
- **ArtisanZ HEAD:** `ebbb61265` (161 commits ahead of merge-base).
