# Upstream Artisan v5.0.1 Merge Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Merge upstream Artisan v5.0.1 (`master` at `f358d574f`) into ArtisanZ through the three-tier branch model (`upstream/master → master → ArtisanZ`), keeping upstream's fixes and features and re-applying ArtisanZ customizations as small patches.

**Architecture:** The merge runs on an isolated integration branch `merge/upstream-5.0.1` in a git worktree, so `ArtisanZ` itself is not touched until the result is verified. The merge commit resolves the 105 textual conflicts (about 90 by rule, the rest by hand). Behaviour that upstream restructured — button styles, recording start, dashboard, lazy imports — is re-applied as small follow-up commits on the integration branch.

```
upstream/master (f358d574f, v5.0.1)
       │  already fast-forwarded locally
       ▼
    master (9349b8ffe → f358d574f, +157 commits)
       │
       ▼  this plan: integration branch, then fast-forward after review
    ArtisanZ (pre-upstream-5.0.1-merge + upstream v5.0.1)
```

**Tech Stack:** git 2.54, Python 3.14.5 (the merged tree requires `>=3.13`), PyQt6 6.12.1, pyqtgraph 0.14.0, pytest 9.2.0, ruff.

## Global Constraints

- **Three-tier branch model (from AGENTS.md):**
  - `master`: mirror-like official baseline. Only fetch/merge from `upstream/master`. NEVER add ArtisanZ features here.
  - `ArtisanZ`: custom branch for charge-target, Cotrix, Chinese localization, GUI modernization. All product work here.
- **Conflict rule (from AGENTS.md):** keep upstream bug fixes/new features and re-apply ArtisanZ customizations as small patches; never overwrite newer upstream files with old local snapshots.
- **Nothing lands on `ArtisanZ` in this plan.** All merge work is committed on `merge/upstream-5.0.1`. Fast-forwarding `ArtisanZ` and pushing the result wait for the owner's review.
- **Preserve:** Cotrix branding (`tastermatrix.com` in `__init__.py`, `plus/service_identity.py`), all `plus/` Cotrix integration, charge target (`charge_manager.py`, `charge_dialog.py`), pyqtgraph renderer and the `plot_*.py` modules, workspace modes and policy (`ui_workspaces.py`), Morandi palette, RoR flick/crash detector, zh_CN translations, the worker sampling pipeline (`processed_frame_worker.py`, `sample_processing.py`), dev simulator, peak p1 proxy.
- **Gain:** v5.0.1 — dashboard view, new themes and UI scale factor, SR900 / Dutch Master Roasters / RoastHubs / Schuilenburg PLC support, Santoker protocol fixes, acaia COSMO, profile loading loop fix, WebEngine replaced by pyfulgur for PDF, lazy imports.
- **License:** upstream is AGPLv3 since `1604ca592`. Merging makes ArtisanZ an AGPLv3 derivative. Acknowledged by the owner on 2026-11-24.
- **Python floor becomes 3.13** (`pyproject.toml`: `requires-python = '>=3.13'`).
- **Translations:** the 31 non-zh_CN `.ts` / `.qm` files stay byte-identical to upstream and are never regenerated on ArtisanZ, so future syncs do not conflict on them. Only `artisan_zh_CN.ts` is maintained here.
- **Upstream ref:** `upstream/master` = local `master` = `f358d574f` (v5.0.1, 2026-11-23).
- **Merge base:** `9349b8ffe` (v4.2.1, 2026-06-30).
- **Pre-merge test baseline** (ArtisanZ `e726bd955`, old venv): 3052 passed, 73 failed, 6 collection errors. All 73 failures pre-exist this merge: 26 need `pytest-asyncio`, 27 are in `test/unitary/plus/test_login.py`, 16 plot-renderer tests hit a matplotlib `set_clip_path` TypeError, 1 is `test_util.py::test_isOpen`.

## Silent Breakages (verified on the dry-run result)

These do not show up as conflicts, or hide inside a conflict that looks trivial:

1. **`self.start_recording_on_exit`** — upstream `2867f6ad7` removed the parameter. Two ArtisanZ lines in `roast_properties.py` read it outside any conflict; the assignment auto-merges away → `AttributeError` on dialog OK.
2. **`self.pid` is `None`** — `canvas.py` `__init__` auto-merges to upstream's `self.pid:pid.PID|None = None`; the lazy construction sits inside the `sample_processing` conflict. ArtisanZ's `_continue_thermal_result` calls `self.pid.update`.
3. **`sample_processing`** — resolve toward ArtisanZ's worker chain and port upstream's 11 hunks (−12/+15 lines). Upstream's side double-processes every sample.
4. **`svgsupport`** (deleted upstream) is used in ArtisanZ's `VMToolbar._icon`; **`get_unit_name`** is now a function-local import upstream but ArtisanZ's `default_xlabel_text` calls it bare.
5. **Button styles** — `event_button_style.py` and `slider_style.py` became functions in `styles.py`. ArtisanZ's Morandi colours live in the old places.
6. **Cotrix brand swap** — `translatedServiceMessage` replaces the literal `'artisan.plus'`; upstream reworded those strings.
7. **QtQuick** — upstream dropped it from the macOS spec's `Qt_modules` and made it an active exclude on Linux; ArtisanZ's QML workspace dock needs it.
8. **Mode layer** — upstream `UI_MODE` vs ArtisanZ `WorkspaceMode`; upstream's new shortcuts bypass the workspace policy; the policy knows nothing about the dashboard.
9. **Themes** — rename detection turns `Artisan.athm` into the target of upstream's `Default.athm` changes; upstream `load_dark_theme()` loads Catppuccin Macchiato on first start in dark mode.

Verified NOT to be a risk: upstream renamed no Python identifiers (`c60ac9e9c` "Signal => Curve" touches only `src/proto/artisan_roast.proto`); all 48 ArtisanZ-only modules import cleanly on top of pure upstream; no ArtisanZ-only module references anything upstream removed; no `.ui` objectName changed; QSettings organisation/application names are unchanged; the charge-target feature and upstream autoCHARGE / `CHARGE_time` are complementary.

- [x] **Step 2: Insert ArtisanZ-only messages into zh_CN** — save as `/tmp/az-merge/merge_zh_cn.py`

```python
#!/usr/bin/env python3
"""Copy ArtisanZ-only messages into upstream's artisan_zh_CN.ts.

Usage: merge_zh_cn.py <worktree> <pre-merge-ref>
A message is keyed by (context, source text, source comment). Only messages that
exist in the pre-merge ArtisanZ file and not in the upstream file are inserted.
"""
import re
import subprocess
import sys
import xml.etree.ElementTree as ET

CONTEXT_RE = re.compile(r'[ \t]*<context>.*?</context>\n?', re.S)
NAME_RE = re.compile(r'<name>(.*?)</name>', re.S)
MESSAGE_RE = re.compile(r'[ \t]*<message>.*?</message>\n?', re.S)
TS_PATH = 'src/translations/artisan_zh_CN.ts'


def context_blocks(text):
    return [(m.start(), m.end(), m.group(0)) for m in CONTEXT_RE.finditer(text)]


def key_of(name, block):
    message = ET.fromstring(block.strip())
    source = message.find('source')
    return (name,
            source.text if source is not None else '',
            source.get('comment') if source is not None else None)


def main(worktree, ref):
    with open(f'{worktree}/{TS_PATH}', encoding='utf-8') as fh:
        up = fh.read()
    az = subprocess.run(['git', '-C', worktree, 'show', f'{ref}:{TS_PATH}'],
                        capture_output=True, check=True).stdout.decode('utf-8')

    additions = {}        # context name -> [message blocks]
    new_contexts = []     # whole contexts missing upstream
    up_by_name = {NAME_RE.search(b).group(1): b for _, _, b in context_blocks(up)}
    for _, _, az_block in context_blocks(az):
        name = NAME_RE.search(az_block).group(1)
        if name not in up_by_name:
            new_contexts.append(az_block.rstrip('\n'))
            continue
        known = {key_of(name, m.group(0)) for m in MESSAGE_RE.finditer(up_by_name[name])}
        for m in MESSAGE_RE.finditer(az_block):
            block = m.group(0)
            if 'type="vanished"' in block:
                continue
            if key_of(name, block) not in known:
                additions.setdefault(name, []).append(block.rstrip('\n'))

    # insert from the end so earlier offsets stay valid
    for name, blocks in additions.items():
        start, end, text = next(c for c in context_blocks(up) if NAME_RE.search(c[2]).group(1) == name)
        head, _, tail = text.rpartition('</context>')
        up = up[:start] + head + '\n'.join(blocks) + '\n    ' + tail + up[end:]
    for block in reversed(new_contexts):
        up = up.replace('</TS>', block + '\n</TS>')
    with open(f'{worktree}/{TS_PATH}', 'w', encoding='utf-8') as fh:
        fh.write(up)
    print(f'inserted messages: {sum(len(v) for v in additions.values())} in {len(additions)} contexts; '
          f'new contexts: {len(new_contexts)}')


if __name__ == '__main__':
    main(sys.argv[1], sys.argv[2])
```
