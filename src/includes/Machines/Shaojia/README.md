# Shaojia Direct-Fire 2kg — 烘焙机 ArtisanZ 预设

针对一台国产直火式（Direct-Fire）2kg 烘焙机的 ArtisanZ 机器预设。通过 Wireshark 抓包 +
Modbus relay 反向工程确认的协议规格。

## 协议规格

| 项 | 值 |
|---|---|
| 协议 | 标准 Modbus TCP |
| IP | `192.168.10.100`（可通过路由器 DHCP/静态绑定调整） |
| 端口 | `TCP 1053`（非标准端口，但协议本身完全标准） |
| Unit/Slave ID | `1` |
| 字节序 | Big-Endian（网络序） |
| 数据类型 | 16-bit 无符号整数 |
| 温度单位 | 1°C（不是 0.1°C） |
| 轮询周期 | 操控电脑约 3 秒一次，分两个请求读 HR[0..10] + HR[11..27] |

## 如何加载

1. 启动 ArtisanZ
2. 菜单：**Config → Machines → Shaojia → Direct Fire 2kg**
3. 弹出确认对话框，点 OK（会保存当前配置以便取消恢复）
4. 确认连接：状态栏应显示 MODBUS 已连接 `192.168.10.100:1053`
5. 主界面应显示两条曲线：
   - BT（豆温，红色）≈ 室温 28-29°C（冷机）
   - ET（排风温，蓝色）≈ 室温
6. 扩展曲线（Inlet 进风温、Fire 火力、Damper 风门、DamperPos 风门位置）在 LCD 面板可见

## ⚠️ 安全注意事项

**首次测试务必在冷机状态进行，并按以下顺序逐步验证：**

### 第一阶段：只读验证（安全）
1. 加载预设后，**先不要点任何控制按钮**
2. 观察 BT/ET 曲线是否显示合理室温（28-29°C）
3. 启动烘焙机加热（用烘焙机本身的操控电脑，不用 ArtisanZ）
4. 看 ArtisanZ 的 BT/ET 是否跟随上升 → 确认寄存器映射正确

### 第二阶段：滑块验证（中等风险）
1. 冷机状态下，拖动「火力」滑块到 50
2. 看烘焙机操控电脑的火力显示是否变成 50
3. 同样测试「风门」滑块
4. 确认读写的方向和单位正确后再实际使用

### 第三阶段：按钮验证（高风险）
⚠️ **这些按钮会直接控制烘焙机硬件**。共 8 个按钮分两类（都做了点击后视觉复位）：

**触发型（写 1 触发一次动作）** — 点击后自动弹起，可连续点：
- **Fire +10 / Fire -10** — 火力增减 10（HR[21]/[22]）
- **Damper +10 / Damper -10** — 风门增减 10（HR[23]/[24]）

**开关 toggle 型（点一下开、再点一下关）** — 第 1 次点写 1（开），第 2 次点写 0（关）：
- **Main PWR（主机开关）** — 启停整个烘焙机（HR[11]）
- **Ign（点火）** — 点燃燃烧器 🔥（HR[17]）
- **Cool（冷却）** — 启动冷却风机（HR[13]）
- **Stir（搅拌）** — 启动搅拌电机（HR[15]）

测试建议：
- 先在烘焙机本地操控电脑上**手动开启**对应功能
- 然后用 ArtisanZ 按钮**关闭**它（toggle 按钮再点一次就关）
- 确认 ArtisanZ 能正确控制后，再尝试从 ArtisanZ **开启**

⚠️ **toggle 方向假设**：按钮假设烘焙机寄存器逻辑是「写 1=开，写 0=关」。如果第一次点击
反而关闭了已开启的功能，说明逻辑相反——告诉开发者把 `1-$` 改成 `$` 即可反转。

### 如果方向反了
如果加热后 ArtisanZ 显示的温度**不上升反而下降**，或 BT/ET 互换了：
- BT/ET 互换：菜单 **Config → Device Assignment** 里交换 ET/BT 通道
- 温度不上升：检查 `input1div`/`input2div`，可能需要改成 `1`（0.1°C 单位）

## 故障排查

| 症状 | 可能原因 | 解决 |
|---|---|---|
| 连不上 | IP/端口错 | 检查烘焙机 IP 是否仍为 192.168.10.100，端口 1053 |
| 连不上 | IP 冲突 | 确认你的电脑 IP 不是 .100 |
| 温度显示 0 | 寄存器地址错 | 用 `scripts/roaster_sniff.py` 复核寄存器值 |
| 温度显示 280 而非 28 | 单位错 | `input1div`/`input2div` 改成 `0`（1°C 单位） |
| 按钮/滑块无效 | unit ID 错 | 确认 `writeSingle(1, ...)` 第一个参数是 1 |
| 烘焙机状态错乱 | 写命令语义错 | **立即停止**，用操控电脑恢复，复核寄存器含义 |

## 调试工具

仓库根目录的 `scripts/` 下有几个调试脚本：

```bash
# 读所有寄存器（只读，安全）
python3 scripts/roaster_sniff.py --count 10

# 受控实验：操作烘焙机，找出对应寄存器
python3 scripts/roaster_diff.py

# 协议探测（不知道协议时用）
python3 scripts/roaster_probe.py probe 192.168.10.100
```
